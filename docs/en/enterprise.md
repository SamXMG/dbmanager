# Enterprise Roadmap (planned)

To be clear up front: the open-source edition remains fully usable forever. If any of the
features below are built, they are **additional management capabilities on top of the
open-source edition** — existing features will never be moved behind a paywall.

Development has not started yet; it proceeds based on community feedback and enterprise
subscription demand — whichever need is clearly defined gets built first.

## Candidate features

| Feature | Problem it solves |
|---|---|
| Team account center | Unified accounts per team, bulk import, bulk role adjustments, LDAP group mapping |
| Centralized audit reporting | Aggregated audit-log statistics, compliance export (PDF/Excel), anomaly alerts |
| SAML / OIDC single sign-on | Connect to existing identity providers (Okta, Feishu, DingTalk, ADFS); LDAP stays free |
| Bulk permission management | Connection × user permission matrix, templated authorization, approval flows |
| Offline installer & internal registry | Installer for air-gapped environments, mirror registry, centralized upgrades |
| Dedicated support | Corresponds to the Enterprise tier in SUPPORT.md |

## How it's done

Each feature is developed, priced, and released independently, without blocking the
open-source mainline. The clearest current need is the team account center — development
starts once a few interested enterprises line up. For a demo or deployment plan, reach us
via the contact info in SUPPORT.md.
