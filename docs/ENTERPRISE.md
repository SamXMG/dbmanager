# 企业版路线图（规划中）

先说清楚一点：开源版永远完整可用。下面这些功能如果做出来，也是开源版之上额外的管理功能，不会把现有功能改成收费。

当前还没开始开发，按社区反馈和企业订阅的需求推进，哪个需求明确就先做哪个。

## 候选功能

| 功能 | 解决什么问题 |
|---|---|
| 团队账号中心 | 多团队统一账号、批量导入、角色批量调整、LDAP 组映射 |
| 集中审计报表 | 审计日志汇总统计、合规导出（PDF/Excel）、异常行为告警 |
| SAML / OIDC 单点登录 | 接企业已有的身份源（Okta、飞书、钉钉、ADFS）；LDAP 仍然免费 |
| 批量权限管理 | 连接 × 用户权限矩阵、模板化授权、审批流 |
| 离线安装包与内网仓库 | 无外网环境的安装器、镜像仓库、集中升级 |
| 专属支持 | 对应 SUPPORT.md 里的 Enterprise 档 |

## 怎么做

每个功能独立开发、独立定价、独立发布，不阻塞开源主线。目前最明确的需求是团队账号中心，攒够几家意向企业就开工。想看演示或部署方案，按 SUPPORT.md 里的联系方式找我们。
