# DB Manager 用户手册

> 适用于 DB Manager 1.4.x。面向日常使用数据库管理的开发、DBA 与运维人员。

## 1. 产品简介

DB Manager 是一个**多数据库统一管理工具**（对标 Navicat / DBeaver 的高频场景）：
一个 Web 应用同时管理 **SQLite / MySQL / PostgreSQL / SQL Server / Oracle / MongoDB / Redis**，
并兼容 OceanBase / TiDB / KingbaseES（协议归一化）。内置账号体系、读写权限、LDAP/AD、
连接级 ACL、审计日志与传输加密，适合个人、内网团队与企业私有化部署。

## 2. 快速上手

### 2.1 启动

```bash
python -m pip install -r requirements.txt
python app.py            # 默认 http://127.0.0.1:8770，自动打开浏览器
```

Windows 也可双击 `scripts/setup_new_pc.bat`（自动安装依赖并启动）。

### 2.2 首次登录（重要 · 请先读完）

> ⚠️ **首次部署必读 —— 初始密码不再是固定的 `admin123`**
>
> 默认管理员**账号名固定为 `admin`**，但**初始密码不再固定为 `admin123`**，而是：
>
> - **未配置初始密码时（推荐）**：首次启动系统自动生成一个 **16 位高熵随机口令**（大小写字母 + 数字 + 符号）。
>   该口令**只在启动日志打印一次**——启动控制台（运行 `python app.py` 的终端窗口）以及 `logs/dbmanager.log`
>   （搜索关键字 **「初始口令」**）。**它不会显示在登录界面上，也不会以明文落盘**，请启动后立刻查看日志并记下来，然后登录改密。
>   （提示：随机口令也会留在 `logs/dbmanager.log` 中，生产环境改密后建议清理该日志行。）
> - **已配置初始密码时**：若设置了环境变量 `DBM_DEFAULT_PWD` 或 `dbmanager.conf` 的 `[auth] default_pwd`，
>   则初始密码取该值（⚠️ 该值会**明文写入配置文件 / 环境变量**，**存在弱口令风险**，仅建议留空由系统随机生成）。
>
> **首次登录后系统会强制要求修改默认密码**，改密完成前无法使用业务功能。

获取初始口令（随机生成场景）的两种方式：

1. 启动控制台：运行 `python app.py` 的终端窗口会打印一段以 `=` 分隔的提示块，含 `用户名: admin` 与 `初始口令: <随机串>`；
2. 运行日志：打开 `logs/dbmanager.log`，搜索 **「初始口令」** 即可定位。

登录地址：`http://127.0.0.1:8770`（或你的局域网 / 公网地址）。

> 建议登录后立刻在「账号管理」中创建普通账号（只读 / 读写角色），并为生产库连接勾选「强制只读」。

### 2.3 建立连接

1. 点击「新建连接」，选择数据库类型，填写主机/端口/账号/密码；
2. 支持 SSH 隧道（跳板机）与云厂商连接模板；
3. 密码通过 RSA-OAEP 加密传输、AES-GCM（Windows 上 DPAPI 绑机）加密落盘；
4. 保存后连接以卡片形式出现在左侧「我的连接」，可双击展开库/表对象树。

## 3. 核心功能

### 3.1 数据浏览（DataGrid）

- 分页网格：排序（点击列头）、筛选（列头 ▾ 面板）、行选中、单元格编辑；
- 大表优化：>300 行自动虚拟滚动、流式「加载全部」（上限 5 万行）；
- Excel 批量粘贴插入：复制表格内容直接粘贴到网格即可批量插入；
- 列宽拖拽、排序/筛选/页大小跨会话记忆（按表维度）；
- 类型着色：数字右对齐、日期/布尔着色、NULL 斜体灰显。

### 3.2 SQL 工作台

- CodeMirror 6 编辑器：关键字高亮、表/字段自动补全、Ctrl+Enter 执行；
- 多语句批量执行 → 每语句一个结果 tab；
- **写模式**：执行写操作（INSERT/UPDATE/DELETE/DDL）前有危险确认；
- 历史/收藏（跨会话保留）、SQL 格式化（Ctrl+Shift+F）、EXPLAIN 可视化；
- 结果表格内过滤（不重新查询）、导出 CSV/Excel。

### 3.3 对象管理

- 表设计器：字段/索引/外键/触发器，实时 SQL 预览；
- 存储过程/函数/触发器：查看源码、保存重建、参数化执行、删除；
- ER 关系图、结构对比/同步、数据级同步（跨表/跨库/跨连接）。

### 3.4 工具

- 查询构建器（可视化拼 SELECT）、数据导入向导（CSV/XLSX 列映射）、测试数据生成器；
- 备份/还原（SQL 文本，BLOB/日期规范化 round-trip）；
- 调度任务：定时备份（按分钟周期，任务引用已保存连接）；
- 数据字典导出、DB 用户与权限查看。

### 3.5 MongoDB / Redis

- MongoDB：集合浏览、JSON 条件查询（`{"age": {"$gt": 30}}`，拒绝 `$where` 等代码执行操作符）、
  文档增删改（按 `_id`）；
- Redis：键浏览（string/hash/list/set/zset 五结构表格化）、新建键/编辑/TTL/删除键。

## 4. 账号与权限

| 角色 | 可执行 |
|---|---|
| read（只读） | 浏览数据、查询、导出、EXPLAIN |
| write（读写） | 只读 + 增删改、导入、备份还原、DDL |
| admin（管理） | 读写 + 账号管理、连接可见性/只读标记配置、网关令牌、关机 |

- 登录限流：同一 IP+账号连续失败 5 次锁定 5 分钟；
- 生产库保护：连接可标记 `read_only`（强制只读，写操作 403）；
- 连接可见性：`visible_to` 控制谁能看到/使用某连接（admin 可配置）；
- LDAP/AD：设置 `DBM_LDAP_URL`/`DBM_LDAP_BASE` 后可直接用域账号登录（角色按本地配置）。

### 细粒度权限（按库/表配置读写）

管理员可在「账号管理 → 用户行「权限」」为每个用户配置**连接（库）级**权限：

- 每个连接可分别开/关 **读** 与 **写**；
- 表范围三选一：**全部表** / **仅指定表（白名单）** / **禁止指定表（黑名单）**，
  支持一键拉取该连接的真实表名勾选，也可手动输入；
- 未配置的连接对该用户**不可见、不可访问**；admin 不受任何权限限制；
- 支持**批量配置**：在账号管理中勾选多个用户 → 「批量设置权限」，一次应用到所有人；
- 权限**立即生效**：已登录用户下一次请求即被服务端拦截（无需重连）；
- 白名单/黑名单会同步作用于对象树（只显示有权限的表）与 SQL 控制台（语句表名越权被拒）。

> 说明：权限配置只影响**连接名**匹配的保存连接；手动输入的临时连接（非保存连接）不适用。
> 已配置过权限的用户，其可访问连接集合 = 权限中授权的连接（原有 `visible_to` 仍然有效，两者取并集）。

### 在线用户管理（实时 + 踢下线）

顶栏「**在线用户**」（仅 admin）：每 5 秒自动刷新的在线列表，显示每个用户的
**用户名 / 角色 / 登录时间 / 来源 IP / 最后活跃 / 当前操作 / 会话数**（同一账号多设备登录会聚合并计数）。

- 点「**踢下线**」需二次确认，确认后该用户的**全部会话**立即断开（重新登录前无法使用）；
- 不能踢自己；踢下线与权限配置均有审计记录。

### 自助注册与审批（局域网团队场景）

本工具定位是局域网内**一次性部署**：管理员部署一次，团队成员无需安装客户端，浏览器访问即可。

1. 成员在登录页点「注册」，提交用户名和密码；
2. 注册的账号处于**待审批**状态，此时**不能登录**（登录会提示"账号待管理员审批"）；
3. 管理员登录后点顶栏「**账号管理**」：对待审批账号点「批准」（选择只读/读写角色）或「拒绝」；
4. 批准后成员即可登录使用；被拒绝的账号无法登录；
5. 管理员也可在账号管理里直接「新建用户」（无需审批），或调整已有账号的角色、删除账号。

> 自助注册默认开启；公网/合规场景可用 `DBM_ALLOW_REGISTER=0` 关闭（改为仅管理员建号）。

## 5. 审计与日志

- 关键操作（登录/增删改/SQL 写/还原/导入/任务/改密）写入 `logs/audit.log`，
  格式 `时间|IP|操作|详情|用户`，5MB 自动轮转；
- 运行日志 `logs/dbmanager.log`（5MB × 3 轮转），含请求日志
  `方法 路径 状态 耗时 user=`；
- 审计日志不可由前端关闭，适合合规场景。

## 6. 常见问题

**Q：忘记 admin 密码？**
停止服务后重置数据库中的 admin（`dbmanager.db`，可用 sqlite 工具或删除该文件的 users 表记录再启动，
将重新创建默认账号；`is_default` 标记可删除以免强制改密）。重置前请先备份 db 文件。

> 注意：随机生成的初始口令**只打印在启动日志一次**，系统不保存明文，遗忘后无法从界面找回，
> 只能按上述方式重置。因此**首次启动拿到口令后应立刻改密并记录**。

**Q：登录后提示"请先修改默认密码"但改密失败？**
改密接口要求旧密码正确、新密码至少 6 位；若用 LDAP 账号登录则走本地改密路径，
请联系管理员。

**Q：局域网/公网如何访问？**
显式设置 `DBM_HOST=0.0.0.0` 监听非回环地址；公网部署必须启用 HTTPS
（`DBM_SSL=1`）并配合网关令牌，详见《部署指南》。

**Q：为什么某些数据库连不上？**
- SQL Server 需本机安装 ODBC Driver 17/18（仅 Windows 桌面版需要）；
- Oracle 使用 python-oracledb thin 模式，无需安装客户端；
- Redis 5 及以下会自动使用 RESP2 协议，无需额外配置。
