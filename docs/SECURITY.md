# 安全说明（Security）

DB Manager 面向**内网/团队数据库管理**，安全设计贯穿始终。发现安全问题时请
**先私密报告，不要公开披露**（公开 PoC 会给未升级用户带来风险）。

## 报告漏洞

- 首选：GitHub 私密方式——在仓库 `Security` 页签创建 **Security Advisory**
  （或联系维护者私信/邮箱，见仓库主页）；
- 请在报告中包含：影响版本、漏洞类型（注入/越权/DoS/凭据泄露等）、
  复现步骤或最小 PoC、受影响接口路径；
- 一般处理周期：确认后 **14 天内** 修复并发布补丁版本，随后在 CHANGELOG 披露（不含 PoC 细节）。

## 安全模型速览（供审查者参考）

| 层面 | 机制 |
|---|---|
| 鉴权 | 账号体系（PBKDF2-SHA256 12 万轮）、RBAC 三档（read/write/admin）、登录限流（5 次锁 5 分钟）、LDAP/AD 可选 |
| 强制首改密 | 默认账号未改密前业务 API 全局 403（`must_change_pwd`） |
| 加密 | 连接密码 AES-GCM 落盘（Windows 绑 DPAPI）+ RSA-OAEP(SHA-256) 传输；密钥文件 0600 |
| 注入防护 | 数据层标识符白名单 + 参数化 + 方言转义；SQL 只读逐语句门禁 + SELECT INTO 封堵；Mongo 拒绝 `$where` 等代码执行操作符 |
| 查询限额 | 无 LIMIT 的 SELECT 自动追加（默认 500/上限 5000）、请求体 100MB 上限、登录与会话限流 |
| 传输 | 默认绑定 127.0.0.1；可选 HTTPS（自签或自有证书，Cookie Secure 联动）；公网网关令牌（内网 IP 免验证） |
| 头/审计 | CSP、X-Frame-Options DENY、nosniff；关键操作审计日志（时间\|IP\|操作\|详情\|用户，轮转） |
| DoS 面 | 请求体 413 上限、查询 LIMIT 兜底、会话惰性清理、连接池上限 |

## 已接受的边界（信任模型）

- **内网信任模型**：RFC1918/回环/链路本地客户端免网关令牌（网关仅约束公网访问）；
- 生产库只读保护依赖连接配置标记 `read_only`（写操作 403），管理员负责正确标记；
- 审计日志服务于合规留痕，若被本机 root 级攻击者直接删改文件则无法防御（非本软件范围）。

## 发布清单（维护者）

开源发布/发版前：确认 `users.json`/`connections.json`/`.dbm_*`/`logs/`/`localdb/`
不入库（已 gitignore）；禁止在 commit message 或代码注释中写入真实凭据；
tag `v*` 触发 Release 流水线全量验证。
