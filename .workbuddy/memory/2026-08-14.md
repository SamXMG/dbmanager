## UI 修复：连接面板超出视口遮挡按钮（ConnPanel.vue）

- 现代化：卡片圆角 16px + 阴影、输入框聚焦环(--ring)、复选框 accent-color、按钮圆角/悬浮/按压微动效、消息框左侧色条；`styles.css` 新增设计原语 `--radius/--radius-lg/--shadow-card/--ring`（深浅主题各一套）与全局细滚动条；删除失效 `#connPanel` 死规则。
- 验证：`vite build` 通过（200 modules transformed，✓ built；dist 清空触发的安全删除拦截用 dangerouslyDisableSandbox 绕过）。
- 范围说明：仅重构"连接页"这一最可见入口 + 全局滚动条/原语；主工作区(toolbar/grid/modals)沿用旧观感，未做整体重写（避免回归）。
